- 🚀 The strongest apps use **FastAPI**, **LangChain**, **Ollama**, and **SQLite**

### 🧠 AI & Development Stack

Used in the public repositories:

- **Python applications**: FastAPI, Django, SQLite, pytest, Pydantic
- **Local LLM apps**: LangChain, Ollama, DuckDuckGo search (`ddgs`) in the web-search agent
- **Machine learning**: scikit-learn, pandas, NumPy, joblib
- **Deep learning**: PyTorch (CPU builds in [Deep-Learning-Projects](https://github.com/muhammadsajjad2710/Deep-Learning-Projects))
- **Interfaces**: HTML, CSS, JavaScript, plus CDN React, Vue, Alpine, Preact, Lit, and Bootstrap in [Frontend-Projects](https://github.com/muhammadsajjad2710/Frontend-Projects)
- **Automation files**: n8n workflow JSON and Zapier recipes in [AI-Automation-Projects](https://github.com/muhammadsajjad2710/AI-Automation-Projects)

Declared, but not a hand-written feature in the app code I reviewed:

- **LangGraph** is a dependency of [Agentic-AI-Projects](https://github.com/muhammadsajjad2710/Agentic-AI-Projects). The web-search agent calls LangChain `create_agent`.

Not shown as working code in the repositories reviewed for this README: Qdrant, Pinecone, Chroma, pgvector, LangSmith, hosted OpenAI, AWS, Redis, Celery, and a network MCP server. I removed those from the stack list.

### ⭐ Selected Projects

#### [Agentic-AI-Projects](https://github.com/muhammadsajjad2710/Agentic-AI-Projects)
Local chat apps. The web-search agent uses LangChain `create_agent`, Ollama, and DuckDuckGo. FastAPI serves the UI and SQLite stores conversations. Tests mock the model. **There is no authentication. Do not expose it publicly.**

#### [Generative-AI-Projects](https://github.com/muhammadsajjad2710/Generative-AI-Projects)
Ten FastAPI apps that call Ollama to generate text (stories, email, code, summaries, and similar). These are prompt-and-generate apps, not tool-using agents. No authentication.

#### [Machine-Learning-Projects](https://github.com/muhammadsajjad2710/Machine-Learning-Projects)
Ten scikit-learn exercises (regression, classification, clustering, and text) with tests. No GPU and no paid APIs.

#### [Deep-Learning-Projects](https://github.com/muhammadsajjad2710/Deep-Learning-Projects)
Ten PyTorch exercises: CNNs, an LSTM, a small transformer classifier, a U-Net, a DCGAN, and related models. `requirements.txt` pins `torch==2.15.0` with NumPy, pytest, and scikit-learn.

#### [FastAPI-Projects](https://github.com/muhammadsajjad2710/FastAPI-Projects)
Ten local FastAPI examples, including CRUD, JWT, WebSockets, uploads, and background jobs. Local demos, not deployed services.
